# 📖 Blog Clone Web

A **Personal Blog Clone Website** created while following a tutorial.  
This project was a hands‑on exercise to learn the basics of building and styling a blog platform.

---

## 🚀 Features
- 📝 Display blog posts with titles and content
- 🎨 Clean and simple design
- 📂 Organized file structure
- 🌐 Responsive layout for different screen sizes

---

## 🛠️ Tech Stack
- **HTML5** – structure
- **CSS3** – styling
- **JavaScript** – interactivity (optional)

---

## 📚 Purpose
The goal of this project was to:
- Practice core web development skills
- Understand how a blog site is structured
- Gain confidence in working with HTML, CSS, and JS
